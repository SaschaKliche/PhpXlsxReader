# Security Policy

This security policy applies to public projects under https://github.com/SaschaKliche.

## Security Versions

Security fixes are generally provided only for the last minor version.
Fixes are released either as part of the next minor version or as a patch version.

Security fixes might be enough to cause a new version to be released and
are released as soon as possible.

## Reporting a Vulnerability

We encourage responsible disclosure of security vulnerabilities.
If you find something suspicious, we encourage and appreciate your report!

In order for the vulnerability reports to reach maintainers as soon as possible,
please use the "Report a vulnerability" button under the "Security" tab of the associated GitHub project.
This creates a private communication channel between the reporter and the maintainers.  
Thank you very much for your effort!
